# طاولتنا

موقع الشلة لتسجيل قيمات الألعاب اللوحية، تقييمها، ومين يكسب مين.

- `app/` الموقع (React + Vite). بدون إعدادات Supabase يشتغل بوضع تجريبي ببيانات وهمية.
- `supabase/schema.sql` قاعدة البيانات والصلاحيات. الكتابة كلها تمر عبر دوال تتحقق من رمز اللاعب.
- النشر تلقائي على GitHub Pages مع كل push على `main`.

التشغيل محلياً: `cd app && npm install && npm run dev`
